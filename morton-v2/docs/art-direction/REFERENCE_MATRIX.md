# REFERENCE MATRIX — 借鉴方法 / 明令禁止借鉴内容

四个参考是**一套互补的版式语法**，不是四个风格选项。本文件只记录"方法层"的借用与禁止层。

| 参考 | 具体方法（我们借的） | 落在哪一屏 | 明令禁止（不借的） |
|---|---|---|---|
| **Lujo Living**（lujoliving.com） | ① 一张图占满一段，图本身承担"物"的重量；② 文字退到画面边缘（左下 28–44px 标题 + 12px 正文），不压主体中心；③ 材料/光线真实，颜色由图像决定 | 01 Hero（材质窗口承担"物"）、04 Focus（52vw 主图） | 家具产品图、品牌 logo、任何 Lujo 摄影资产；不做"产品列表页" |
| **Cartier**（cartier.com / Decimal 案例） | ① 单件物体 + 微距细节的层级（宏观→细节）；② 信息逐层出现、状态受控；③ 深色场里让物体发光，UI 几乎无色 | 04 Focus（2:1 细节 inset）、01 Hero（深色材质场） | 珠宝图片、Cartier 标志、Cartier 的居中锁版构图（我们不做"大 logo 居中 + 两侧导航"）；不做黑金配色 |
| **Hollywood Exhibit 2026**（osmos.co） | ① 印刷式版式：大标题与小字同屏、图片宽高比变化、直角裁切；② 作品可列表/网格切换；③ 纸张质感与编辑节奏 | 03 Works（4 种比例、目录条）、02 About（大标题+档案表） | 人物肖像、ELLE/Esquire 标题成品、其摄影资产；不做"每章一个大写的字母" |
| **Getty · Tracing Art** | ① 单一主体跨章节连续；② 图文空间叙事，文字与图像互相改变观看角度；③ 极端空场 + 少量强元素 | 00 Cover（空场 + 单一母版线稿）、03 Works（疏密节奏） | 艺术品素材、Getty 的数据库文案、三章内容结构；不做滚动 timeline 复刻 |
| **Heron AI**（仅开场机制，不属美术参考） | 只用：中央水平线、多路径逐笔描绘、中央向上下分离揭幕、底层提前就绪 | 00 Cover 的中央线（40% 不透明度，弱于线稿） | 建筑制图 / CAD / 坐标标注 / 品牌色 / 其 UI。**任何百分比数字都不出现** |

## 一句话结论

> 我们复制的是"画面如何被组织"：直角矩形、整块纯色、隐形网格、极端尺度对比、克制的文字层级、单一焦点。
> 我们**不**复制任何站点的图片、logo、文案、配色或具体商品题材。

## 使用纪律

- 四个参考之间**不得**被当成 A/B/C/D 供用户选择；每一屏同时用到其中 2–3 个的方法。
- 引用参考时，只能引用"行为/结构"（例如"把标题压到图外边缘"），不能引用"他们的某张图好看"。
- 如果某一屏的做法在四个参考里找不到对应方法，先问它是否服务本屏的焦点与节奏，再决定保留。
