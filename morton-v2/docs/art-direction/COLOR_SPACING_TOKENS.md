## 2. 间距台阶（只允许这六级）

`8 / 16 / 24 / 40 / 64 / 96` — `--space-1 … --space-6`。

画面内部的目测间距必须落在这六级上；不允许 13px、27px 这种"手感值"。例外只有两类：字号相关的行高、以及 1px 线本身。

## 3. 栅格

- 桌面：12 列，`--col-gap: clamp(12px, 1.4vw, 24px)`（1440 下 = 20.16px），`--gutter: clamp(22px, 4.5vw, 96px)`（1440 下 = 64.8px）。
- 移动：4 列，`--gutter: 22px`，`--col-gap: 12px`。
- 1440 基准下列宽 = `(1440 − 2×64.8 − 11×20.16) / 12 = 90.72px`；第 N 列起点 = `64.8 + (N−1)×110.88`。
- 页面内**不画**任何网格线。网格只用于对齐：02 的正文列 = 第 8–11 列（841 → 1376−103），03 的右列 = 第 9–12 列，04 的右列 = 第 8–12 列。

## 4. 线

| 用途 | 粗细 | 颜色 |
|---|---|---|
| 分隔 / 表格 / 基线 | 1px | `--divider` / `--divider-inverse` |
| 必须读成边界（按钮、图版边） | 1px | `--divider-strong` / `rgba(27,26,24,.3)` |
| 开场线稿 primary / secondary / tertiary | 1.4 / 0.8 / 0.5px | ink 100% / 65% / 40% |
| 开场中央进度线 | 1px | ink 40% |

0.75px 只出现在开场线稿的 tertiary；**正文界面里没有 0.75px 以下的线**。
