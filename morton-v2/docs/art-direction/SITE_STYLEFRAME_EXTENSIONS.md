# SITE_STYLEFRAME_EXTENSIONS · Phase 3 章节版式规范

Phase 1 定义了五张画面与一套 grammar；Phase 3 把 grammar 扩展到六个章节。
**没有新增颜色、字号、圆角或阴影**——所有章节只用既有 token。

## 1. 章节地图

| # | 章节 | 密度 | 主角 | 版式方法（来自哪个参考的"方法"） |
|---|---|---|---|---|
| 00 | Opening + Hero | 极简 | 材质窗口里的 MORTON | Lujo 的整幅材料 + Getty 的尺度对比 |
| 01 | About / Record | 编辑 | 越缘的 112px 标题 + 纸板 | Hollywood 的图文对照、Cartier 的信息层级 |
| 02 | Record | 编辑 | 三条经历 + 三张不同比例的小图 | Getty 的连续叙事、编辑索引 |
| 03 | Making | 安静 | 68px 追问句 + 三块材料 | Lujo 的材料细节、Cartier 的克制度 |

## 2. 每章的具体构成（1440 基准）

### 01 About
- 纸板 `p01` 占 1–8 列，**左/上出血**，高度 `min(78vh, 720px)`；右下角 `P.01 — PAPER STUDY` 极小标注。
- 标题 8.2vw（≈112px）从第 6 列起，**压过纸板右缘**；`01 — ABOUT / RECORD` 在标题上方。
- 正文第 8–12 列、34ch；`ARCHIVE` 三条 1px 分隔的档案行（年份 / 条目 / 地点）。
- 左下留空，不放任何东西。

### 02 Record
- 三行，每行：年份（1–3 列）· 标题 + 一句话（3–8 列）· 图（9–13 列）。
- 三张图比例不同：`4:5` / `3:2` / `1:1`，并用 0/48/16px 的顶部偏移制造节奏。
- 每行一条 1px 分隔线；行内 `01 / 03` 的索引在句子下方。

### 03 Making
- 68px 的追问句占 3–11 列，两行。
- 三步：`Material / Measure / Record`，各 4 列，顶部偏移 0 / 56 / 112px。
- 每步：`4:5` 图 + 上方 1px 线 + 序号 + 22px 标签 + 一句话。

### 04 Works（唯一的深色展厅）
- 背景 `--gallery`，文字 `--paper`，分隔线用 18% 纸白的 1px。
- 主展品 1–9 列、`16:9`；右侧轨道 9–13 列上下两件 `4:5`；再下一件 `3:2`。
- 每件是 `<button data-project-card>`：caption 用 1px 上分隔线，序号 / 标题 / 类型·年份。
- 底部 `INDEX` 条：两列清单，每行 1px 线，序号 / 标题 / 类型。

### 05 Next
- 顶部 1px 通栏线；`05 — NEXT` + 96px 句子（3–10 列）+ 两行说明（3–7 列）+ 联系信息（9–13 列）。
- 右下角 6 列宽的字标（约 30px cap），作为收束而不是主角。
- 底部 `MORTON — 2026` 与 `Phase 3 skeleton · placeholders in use` 两行小字。

## 3. 移动端（≤719px）重排规则

| 章节 | 变化 |
|---|---|
| About | 纸板改 62vh 通栏出血；标题降到 12.5vw；档案表保留；**隐藏 plate label**（避免与 kicker 重复） |
| Record | 单列：年份 → 标题/句子 → 图（4:3），不再左右分栏 |
| Making | 单列三步，取消 56/112px 偏移 |
| Works | 主展品 4:3 通栏；rail 两列并排；index 单列 |
| Next | 句子 11vw；联系信息移到句子下方 |
| Focus | 上图（52vh）下文单列；back 按钮在信息列顶部 |

## 4. 边界

- 章节**没有**引入滚动劫持、没有 sticky pin、没有横向拖拽；滚动只有原生滚动 + 一次性 reveal。
- 所有图片位都是原创占位材质板；`[作品 01]` 等占位符在真实内容到位前不得删除。
- 深色展厅只用于 Works 一章；其余章节保持纸白，避免"整站一个浅灰底"或"整站一个暗场"。
