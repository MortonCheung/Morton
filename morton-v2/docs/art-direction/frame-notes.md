# FRAME NOTES — 每个元素来自哪个参考的哪种方法，为什么这样排

> 逐屏逐条。参考只以"方法"出现，不引用其任何素材。截图见 `styleframes/`。

## 00 · OPENING COVER（1440×900 / 390×844）

| 元素 | 方法来源 | 为什么这样排 |
|---|---|---|
| 纸白整块底 + 9% 材质底 | Lujo（整屏材质）/ Getty（极端空场） | 9% 只作为"印刷底"存在，让开场与 Hero 的材质板同源；不做成图 |
| 字标描边 = Hero 同一路径、同一 ink box | Getty（单一主体连续）/ Heron（逐笔构建，仅机制） | 00 与 01 并排可重合：Phase 2 的线稿必须能"原地变实" |
| primary 1.4 / secondary 0.8 / tertiary 0.5 三层 | Hollywood（印刷分层） | 三层线宽 + 65%/40% 明度，避免"工程线稿"的均质感 |
| 逐字母 dash（M/O 完成、R 71%、T 23%、O 38%、N 未开始） | Heron（多路径错峰，仅机制） | 表达"已经画到 62%"的中间态；**不用数字** |
| 中央线 74vw / 1px / 40% | Heron（中线机制） | 必须弱于线稿；它只是绘图台的基准，不是进度条 UI |
| 材质板左/上边 + 一条接缝 | Cartier（容器边界）/ Lujo（材质） | 板的四条边里只有两条在画幅内；接缝是材质高光的位置，不是装饰 |
| 四角 11px 标签 | Hollywood（边缘小字） | 修正"空场 = 没做完"的误读；标签只有事实（编号/状态） |

**为什么不是"小字标 + 大裁切字标"两张稿**：Lead 已判定"描了两遍"不成立；一屏只能有一个线稿主体。

## 01 · HERO FINAL（1440×900 / 1440×700 / 390×844）

| 元素 | 方法来源 | 为什么这样排 |
|---|---|---|
| MORTON 101.9vw、衬线出血 13.7px/边 | Getty（极端尺度）/ Hollywood（印刷溢出） | 竖干与画幅齐平 → 品牌可读；只切衬线延伸 → 裁切是"印刷溢出"而非缺字。白缝的根因是 M 的 sidebearing，已用"竖干齐边"解决 |
| 材质板 4:5 从右缘出血、底边 = 字标基线 | Lujo（大块材质）/ Cartier（物体与容器） | 字母"站"在材质上，两者有共同的地平线；不是"大字压色块" |
| 字母镂空（Material Window） | Cartier（材质细节）/ Hollywood（版式与图的关系） | 让字与材料发生物理关系；同一路径两种材料，是 Phase 2 连续性的基础 |
| 基线 1px 贯穿两段 | Hollywood（印刷基线） | 把纸白与材质两半焊在一起，同时承担"溢出感" |
| 左上 index / 右上 plate label / 右下两行说明 / 左下 01—05 | Lujo（边缘文字）/ Getty（左右分列） | 文字全部退到边缘；中心只留字与材质，不做 HUD |
| 移动端 18 / 62 / 20 三段 | 重新构图（非缩放） | 顶/底纸白轨各放一行信息；材质场里字标 92vw 完整不裁；视觉重心 52–56% |

**为什么选 A（尺度裁切）而不是 B（微距主导）**：Hero 的本体是品牌发布，不是作品陈列；字标必须是被构造的主体。B 更适合 03/04（已由作品屏承担）。见 WORDMARK.md §3。

## 跨屏

| 关系 | 做法 |
|---|---|
| 00 → 01 | 同一几何：材质板矩形、字标 ink box、基线；00 只有描边、01 才上墨/上材质 |
| 02 / 03 / 04 的差异 | 02 文字主导（112px 标题压图）、03 图像主导（深场）、04 产品主导（左图右信息）；三屏构图骨架不同 |
| 统一 token | 五屏共用 11px label / 1px 线 / 8-16-24-40-64-96 间距 / 0 圆角 / 纸白或展厅深色 |
| 移动端 | 每屏重新构图（00/01/02/03/04 的移动版与桌面版不是同一坐标系的缩放） |
