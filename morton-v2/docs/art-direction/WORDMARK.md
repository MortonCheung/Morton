# MORTON 字标构造规范

> Phase 1 · 版本 `2026-10-22 · cut A/B/C`
> 生成器：`docs/art-direction/wordmark/build-wordmark.py`（唯一真源，输出 `src/styleframes/wordmark.ts`，页面里渲染的是路径几何，不是 `<text>`）
> 对比图：`docs/art-direction/wordmark/WORDMARK_STUDY.png`
> 未采用字体轮廓：本字标**不是**把 Bodoni Moda 打上去再调字距。M / O / R / T / N 全部由矩形、椭圆弧、直边带按下面的网格重绘。

---

## 1. 为什么重绘

第一轮被判死的根因是「默认字库字形 + 挤出」。本轮字标必须满足三条可验证条件：

1. **每个字母可被拆成构造原语**（矩形 / 椭圆 / 直边带），不是字形文件的黑盒轮廓；
2. **同一套笔画参数**（竖干、细横、衬线、外扩）能解释六个字母的全部墨色区域；
3. **画面里能看到构造痕迹**：M 的平顶底尖、O 的几何椭圆、R 的直斜腿、T 的单细横画——这些都不是 Bodoni Moda 的默认形态。

因此字标与正文的 Bodoni Moda 是**两个物种**：正文字体提供编辑阅读质感，字标是自绘标识。

---

## 2. 构造网格（design units）

坐标：cap height = **1000**，baseline `y = 1000`，y 向下（SVG 约定）。所有数值都是 **25u 的整数倍**。

| 参数 | 值 | 说明 |
|---|---|---|
| cap height | 1000 | 字标唯一基准高度 |
| 模块 u | 25 | 40u / cap；所有尺寸取整到 u |
| 竖干 thick | **124** | 4.96u；M/O/R/N 的竖笔与主弧 |
| 细横 thin | **36** | 1.44u；字标最小墨色宽度 |
| 粗细对比 | **1 : 3.44** | 比 Bodoni Display 的极端对比低，保证 1440 下细笔 ≥ 8px |
| 衬线深度 | 36 | 无托（unbracketed），与细横同厚 |
| 衬线外扩 | 58 | 竖干两侧各 58u |
| 字标墨宽 | 6184 | ink : cap = **6.18 : 1** |
| 字标整体 y | −12 … 1012 | O 上下各 12u overshoot |

### 2.1 逐字母构造

- **M**（ink 宽 1236）
  - 左竖干 `x 0–124`，右竖干 `x 996–1120`，全高。
  - 两条 **124 宽直边带** 从竖干顶斜切到基线中央：左带 `(124,0)-(248,0)-(622,1000)-(498,1000)`，右带镜像。
  - 两带在基线汇成 **124 宽平切底尖**（`498–622`），不是 Bodoni 的尖点——这是 M 的签名细节。
  - 竖干顶、三个脚各一块 `36 × (124+2×58)` 衬线。
- **O**（ink 宽 900）
  - 外椭圆 `rx 450 / ry 512`（上下 overshoot 12），内椭圆 `rx 326 / ry 476`。
  - 环厚：左右 **124**，上下 **36**。孔径比 0.685，纯椭圆，无超椭圆修正。
  - 上下细、左右厚的应力方向固定为垂直轴，与 Didone 一致，但 counter 是数学椭圆，不是字形轮廓。
- **R**（ink 宽 1040）
  - 左竖干 `0–124`；碗由**椭圆环带**构成：外 `rx 260 / ry 270`（圆心 500,270），内 `rx 136 / ry 234`，碗底 y=540。
  - 腿：**直边平行四边形** `(470,520)-(594,520)-(924,1000)-(800,1000)`，斜率 ≈ 34.5°，平切脚。
  - 竖干顶、竖干脚、腿脚三块衬线。
- **T**（ink 宽 820）
  - **36 厚单细横画** `0–820`；竖干 `348–472`；脚一块衬线。
  - 横画两端平切、无衬线：全字标里唯一一条「无托长横」，是 T 的识别点。
- **N**（ink 宽 1076）
  - 左右竖干各 124（`x 0–124` / `x 836–960`）；**124 宽直边带** `(124,0)-(248,0)-(960,1000)-(836,1000)`。
  - 两个开放 counter：上右、下左，均为直边三角形（开口角度由 124 带定义，六个字母统一）。
  - 左上、右下各一块衬线（Didone N 的经典衬线位）。

### 2.2 字距（ink-gap table，不是 advance width）

字距按**墨色边缘之间的净距**定义，衬线已经不占额外边距：

| pair | 衬线版 A | 几何版 B |
|---|---|---|
| M–O | 52 | 66 |
| O–R | 40 | 52 |
| R–T | 36 | 46 |
| T–O | 36 | 46 |
| O–N | 48 | 60 |

衬线版整字净宽 6184（≈ 6.18 cap），几何版 5894（≈ 5.89 cap）。衬线版的 gap 更小，是因为衬线外扩已经提供了视觉呼吸。

## 3. 三个变体

| | A · DIDONE CUT | B · GEOMETRIC CUT | C · MATERIAL WINDOW |
|---|---|---|---|
| 骨架 | 上面 2.1 全部参数 | 同 A，去掉全部衬线 | 同 A，渲染方式不同 |
| 用途 | **主字标**（Hero / Cover 线稿 / 页脚） | 备选：更当代、更硬的读法 | Hero 里的「字与材质焊在一起」 |
| 视觉证据 | 细衬线 + 高对比 + 平顶 M 底尖 | 平切端点，粗细对比保留 | 字母是**材质板上的镂空窗口**：字母内是纸白，字母外是材质 |
| 风险 | 衬线在极小尺寸会消失（≤11px 时改用 B 或纯文字索引） | 少了衬线的「印刷感」，更像时装标识 | 材质板必须是深色，浅色材质上对比不足 |

`WORDMARK_STUDY.png` 三行同尺寸并排。实际采用：**A + C**（字标用 A，Hero 的右半段用 C 的镂空渲染）。

### 3.1 为什么没做「24×6 等宽直角版」

按要求评估过全直角等宽方案，但它会让 **R 和 N 失去可识别性**：R 的碗与腿、N 的斜画在纯直角网格里只能退化为「口 + 竖条」，读成另一个词。等宽也抹掉了 Didone 的对比，整个字标会掉进「科技 logo」区域——正是本轮明确禁止的方向。因此把「简单几何、直角」留在**版式与材质板**层面（0 圆角、直角裁切、1px 线），字标本体保留高对比 + 几何化字形。如果后续仍要等宽版，可在当前生成器里加一个 `monoline=True` 分支，不影响已通过的字标。

## 4. 裁切规则（Crop）

- **只切外缘笔画，不切字母本体**。Hero 里字标宽 `101.2vw`，`left = −0.597vw`：
  - 左：M 左竖干被切 **≈ 8.6px**（笔画宽 29px，约占 30%）；
  - 右：N 右下衬线被切 ≈ 8.6px，N 的右竖干完整；
  - 合计 ≈ 1.2% 字宽——保证 0.5 秒内读出 MORTON，同时两端仍是「出血」。
- **溢出感由基线承担**：一条 1px 基线横穿整个画幅（纸白段 26% 墨 / 材质段 22% 纸白），字母落在线上，线比字走得更远。
- 所有画面里**禁止**把字标裁到字母内部（会读成缺字）。如果未来需要更狠的尺度，改用「单字母 M 作巨型图形」，不改字标本身。

---

## 5. 使用规范

- 最小使用尺寸：**cap ≥ 22px**（小于该值用 B 变体或正文索引文字）。
- 字标外留白 ≥ **0.5 cap**；与 1px 分隔线的最小距离 = 0.25 cap。
- 颜色只有两种：`--ink`（纸白底上）、`--paper`（深色材质上，镂空或反白）。
- 不描边、不加阴影、不渐变、不倾斜、不压扁。字标是平面印刷物。
- 字标不得与正文 Bodoni 同时出现在同一视觉层级上（字标是标识，不是标题）。
