# IMAGE / MATERIAL GUIDE

> 所有图像位都是**原创占位材质板**（由本项目的材质板 Agent 程序化生成），不是真实项目摄影、不是第三方图库、不是获奖作品。画面里通过 plate label（`P.01 — PAPER STUDY` 等）明确标注它是材质研究。

|---|---|---|---|---|
| 01 Hero | 材质板（p06） | 471 : 804（≈0.586） | 上、右、下 | `cover`，高光带保持在字标 cap 之上 |
| 02 About | 主图（p01） | 761 : 706（1.078） | 左、上 | `cover`；折痕竖线落在图左侧 1/3，标题越过右缘处必须是浅色区 |

**规则**
1. 任何图像位都必须有确定比例 + `object-fit: cover`；不得拉伸、不得圆角。
2. 图与纸之间只有一条 1px 内边（`rgba(27,26,24,.16)`；02 主图加强到 `.30`）。
3. 图与字的关系只允许两种：**图压过文字**（不允许）或**文字压过图**（02/01 使用）；01 是"文字从图中镂空"。
4. 同一屏内不得出现两张同比例、同尺寸的图（03 的 A/B 同为 4:5，但宽度/高度与内容都不同，且 caption 共用基线）。

## 2. 材质板的语义（见 ASSET_REGISTER）

| plate | 语义 | 画面里的角色 | 必须保留的特征 |
|---|---|---|---|
| p01 paper | 纸纤维折痕研究（4:5） | 02 主图 / 03 次级 | 一条竖向折痕、受光面要亮 |
| p02 plaster | 灰泥墙面 + 斜阴影（3:2） | 03 主展品 | 右 1/3 的阴影带必须可见（它是"光"） |
| p06 lacquer | 哑光黑漆 + 横向高光带（3:2） | 01 材质窗口 / 04 主图 | 窄高光带、明度不均匀、边缘略失焦 |
| p07 fold | 折纸屏风 + 投影（2:3） | 03 次级 | 物件轮廓 + 地面投影 |
| p07b fold-deep | 折纸屏风深折版（2:3） | 03 次级（3:2 特写裁切） | 折痕的几何阴影 |

> p03 ink / p04 linen / p05 sand / p08 grain 仍在重做，**未用于任何画面**；它们对应的图位暂用同族色块 + 1px 边占位，不得当成材质。

## 3. 镂空（Material Window）规范

01 Hero 的字标是**从材质板里镂空出来的**：
- 字母内填充 `--paper`（纸白），字母外是材质图；两者用同一个路径、同一条基线。
- 实现：同一路径渲染两次，分别被纸白区与材质区裁切；几何误差必须为 0。
- 边缘允许 1px 的"印刷套准缝"（极淡的纸白描边，`rgba(242,239,232,.18)`），但不得出现双线或白边。
- 镂空字母的笔画宽度不得小于 6px（在 1440 下 cap 237 时竖干约 29px，安全）。

## 4. 替换流程（材质板到位后）

1. 把新图放进 `public/assets/plates/`，文件名不变（`p01-…` 到 `p08-…`）。
2. 在 `src/styleframes/parts.tsx` 的 `PLATE_AVAILABLE` 里把对应 id 置为 `true`。
3. 不改任何坐标/尺寸：版式已经按图位的最终比例锁定；只需确认 `object-position` 后重新截图。
4. 更新 ASSET_REGISTER.md 的状态与日期。
5. 若新图改变了"最亮/最暗"区域，允许微调 `object-position`，**不允许**改图位尺寸或裁切比例。

## 5. 禁止

- 用 CSS 渐变/噪点伪造材质；用第三方图片/截图冒充作品；伪造人物、获奖、项目数据。
- 把占位色块当作"最终材质"交付；把同一张图重复铺满一屏。
- 在图上叠加玻璃/阴影/圆角/描边光效。
