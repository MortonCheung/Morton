# MORTON V2 — ART DIRECTION

> Phase 1 交付。状态 **PENDING_VISUAL_APPROVAL**。字体层级见 TYPOGRAPHY.md，色/间距/栅格见 COLOR_SPACING_TOKENS.md，图像位见 IMAGE_MATERIAL_GUIDE.md，字标见 WORDMARK.md。

## 0. 一句话

**一个纸面，一块材质，一个被构造的字标，一条贯穿画幅的基线。** 五屏是同一份印刷物的五个版面，不是五个网站页。

---

## 1. 版式组织 vs 参考素材内容（独立章节，回答"我们到底借了什么"）

四个参考站里**可复制的不是任何一张图、任何一个商品、任何一段文案**，而是它们组织画面的方式。我们把这种组织方式拆成可执行的六条，并逐条落到画面上：

| 组织方法 | 参考出处（方法层） | 落地实现（可检查） | 禁止的误读 |
|---|---|---|---|
| **1. 整块纯色画布** | 四站共同 | 每个 styleframe 只有一块底色：`#F2EFE8` 纸白 ×4，`#181816` 展厅 ×1。没有渐变/噪点铺底。 | 把"参考站的摄影"当成我们的素材 |
| **2. 直角矩形 + 0 圆角** | Cartier 按钮 / Lujo 通栏图 / Getty 白场 | 所有图版、按钮、meta 表格、focus ring 全为直角；`--radius: 0`。 | 圆角卡片、胶囊按钮 |
| **3. 隐形 12/4 列栅格** | Hollywood 印刷版式 | 内容落在 12 列（1440 下宽 90.72 / gap 20.16）；页面不画网格线。 | 为"高级感"画满辅助线 |
| **4. 极端尺度对比** | Getty 的 90px 字 vs 12px 小字 / Lujo 44px 标题 vs 整屏图 | 字标 cap 237px 对 11px label（21.6:1）；About/Focus 标题 112px 对 11px。中间尺寸被刻意压到只剩一种。 | 全站 60–80px 万能标题 |
| **5. 文字在边缘，主体在中心之外** | Lujo 左下、Getty 左右分列、Cartier 边缘导航 | Hero 的 index 在左上、说明在右下（都在材质上/外缘）；About 标题压在图的右缘；Focus 的 back 在右上。 | "字标居中 + 两侧三行小字" |
| **6. 颜色由图像决定** | Lujo / Cartier | UI 只有纸白/墨/一条线；唯一的深色章节由 Works 的展品决定；材质板的色温决定整屏暖度。 | 用紫色/蓝色科技色或彩色渐变 |

**判断标准**：如果遮住所有图像，只留矩形面积、标题和留白，版面仍然成立（见 ART_REVIEW 第 2、3 问）。如果某条规则只能靠"素材好看"成立，它就不算我们的方法。

## 2. 五层结构（每屏都按此检查）

1. **Canvas / 底**：整块纯色。01/02/04 纸白，03 展厅深色，00 纸白 + 9% 材质底。
2. **Grid / 隐形约束**：12 列（移动 4 列）；对齐点记录在 COLOR_SPACING_TOKENS §3。
3. **Primary exhibit / 主展品**：每屏只有一个。01 = 被材质窗口切开的字标；02 = 主图 + 越过图缘的标题（一个组合焦点）；03 = 62.5vw 主展品；04 = 52vw 展品；00 = 母版线稿。
4. **Editorial / 文字层**：D2（112px）↔ L1（11px）的级差；Cormorant 只用于 02 的长读段；说明控制在 33–34ch。
5. **Motion / 运动层（Phase 2 输入）**：运动必须由"已存在的矩形面/字标路径/材质边缘"决定——00 的线稿路径就是 01 的真实轮廓，所以揭幕可以从 00 连续到 01（见 §6）。

## 3. 五屏构图规则

### 00 Opening Cover
- 画布：纸白；材质板以 **9%** 的 p06 作底（只是一层很淡的印刷底，不是"图"）。
- 几何**严格复用 01**：材质板 x=67.3vw / y=96 / 到画幅右、下；字标 ink box 与 01 完全一致（cap 344–580）；基线 580 贯穿。
- 线稿三层：primary 1.4px（字标外轮廓、板的两条可见边）/ secondary 0.8px（M 斜带、O 内 counter、R 腿、衬线交界，65%）/ tertiary 0.5px（板内接缝、基线，40%）。
- 逐字母 dash 进度 = "已经画到 62%" 的中间态（M/O 完成、R 71%、T 23%、O 23→38%、N 未开始）。**不出现任何数字。**
- 中央进度线 74vw、1px、y=50vh、40% —— 必须弱于线稿。

### 01 Hero Final
- 字标 **101.9vw**，左 −0.951vw；左右各切掉 **13.7px 衬线延伸**（1.9% 墨宽），竖干与画幅边齐平——裁切是"印刷溢出"，不是缺字。
- 材质板 4:5 竖块，**从材质板中镂空出字标**：字母内是纸白，字母外是 lacquer；同一路径、同一条基线、两种材料。
- 基线 1px 贯穿纸白与材质两段；左上 index、右上 plate label、右下两行说明、左下章节序号。

### 02 About / Record
- 主图 52.85vw，左/上出血；正文列 30vw / 34ch（第 8–11 列）。
- 标题 112px，起于图内 x=619，**越过图的右缘**；图加 1px 边线（`.30` ink），让交叠处有硬边，不做"半压不压"。
- 密集区：3 行档案表（1px 线 + 年份/条目/地点）；安静区：右边带 + 底带，不填满。

### 03 Works / Exhibition
- 唯一深色章节 `#181816`；主展品 64.7vw × 55.6vh 左出血；右列三件不同比例（4:5 / 4:5 小 / 3:2）错位；底部 4 列目录条（1px 竖线分隔）。
- 至少 3 种宽高比：1.86 / 0.8 / 1.5；caption 共用同一基线（y=378）；主图与右列间距 = 栅格 gap（20px）。

### 04 Project Focus
- 展品 52vw，上/左/下出血；2:1 细节 inset 直接压在展品上（不是右栏里再放一张卡）。
- 右列：Back to works（1px 直角按钮，键盘可聚焦）→ 112px 标题 → 2×2 meta（1px 线）→ 33ch 说明 → plate register → 页脚字标。
- 标题降部与 meta 上边线保持 ≥32px；不做"标题压线"。

## 4. 材质与光

- 材质**只能来自真实图像版**（p01/p02/p06/p07/p07b），不得用 CSS 伪造纹理。
- 材质要有"被照亮"的证据：p06 的窄高光带证明它是实体；p02 的斜阴影视作墙面的光；p01 的折痕是纸的受光面。
- 所有图版 `object-fit: cover` + 0 圆角 + 1px 内边；图版边缘就是印刷版的裁切线。
- 材质与字的关系只有两种：**压过**（02 标题越过图边）或**镂空**（01 字母是材质窗口）。**不允许**"大字浮在色块上"。

---

## 5. 例外与边界

- 唯一允许的圆角：0px。没有"≤2px"的例外被使用。
- 唯一允许的渐变：无（材质图内的自然明暗不算 UI 渐变）。
- 唯一允许的 opacity 使用：开场线稿的分层（65%/40%）与材质底图（9%）；**文字不用 opacity 降级**。
- 深色只出现在 03 的整屏与 01/04 的材质图上；04 的页脚字标不反白。

---

## 6. MORTON 字标（摘要，完整规范见 WORDMARK.md）

- **不是字体排版**：M/O/R/T/N 由矩形 + 椭圆弧 + 直边带在 cap=1000 网格上构造；竖干 124u、细横 36u、衬线 36×58u；字距按 ink-gap 表（52/40/36/36/48）。
- 签名细节：M 的**平切底尖**、O 的**纯椭圆 counter**、R 的**直斜腿**、T 的**单细横画**。
- 三种用法：实心（01）、材料窗口（01）、描边线稿（00，1.4px 主轮廓 + 0.8px 结构）。
- 最低使用尺寸 cap 22px；不得描边、投影、倾斜、压扁。

---

## 7. 交给 Phase 2 的约束

- 开场线稿只能从 **01 的真实几何**抽取（字标路径、材质板矩形、基线、O 的 counter、M 的斜带），不得新画装饰线。
- 揭幕的目标画面 = 01 Hero 的已完成布局；线稿的坐标与 01 的 ink box 严格对位（00 与 01 并排可重合）。
- 材质板 ready 先于开播；第 2/3 层不得用动画掩盖素材缺失。
